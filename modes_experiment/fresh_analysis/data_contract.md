# Data contract

This contract fixes the inputs used by every fresh-analysis metric and figure.
Machine-readable checks are generated by `scripts/00_build_inventory.py` in
`derived/source_inventory.csv`. A later change to any item below must be logged
in `decisions.md` and requires regeneration of dependent results.

| item | fixed decision | source/check |
|---|---|---|

| Missing values | no deletion or imputation | audit confirms no NaN or infinite values |

`Ur=10^6` is retained as dataset metadata but is not treated as a reconstruction
control parameter. The flow is the fixed-cylinder case.

## Analysis domain and regions

All metrics use the strict crop

\[
-4 < x/D < 8, \qquad -4 < y/D < 4,
\]

which contains 51,654 of the full mesh's 82,872 nodes. Let
`r=sqrt(x^2+y^2)`; the fixed masks are:

| region | exact mask | nodes | relationship |
|---|---|---:|---|
| Near cylinder | `r < 0.75` | 13,715 | partition region |
| Near wake | `r >= 0.75` and `0 <= x < 3` | 15,248 | partition region |
| Far wake | `r >= 0.75` and `x >= 3` | 16,393 | partition region |
| Other | complement of the three regions above | 6,298 | partition region |
| Far core | far wake and `abs(y) <= 2` | 12,460 | nested subset of far wake |
| Whole domain | every node in the strict crop | 51,654 | union of partition regions |

Near cylinder, near wake, far wake, and other form a mutually exclusive
partition. Far core is intentionally not another partition member; it is a
nested wake-focused diagnostic. Figure F0 must appear before regional results.

## Measurements

| case | fixed measurement definition | check |
|---|---|---|
| Pressure taps | 8, 16, or 32 uniform target angles on `r=0.5`, `endpoint=False`; nearest CFD wall node selected | requested counts map to 8, 16, and 32 distinct nodes |
| Sparse velocity probes | 10 uniform target heights at each `x/D = -3, 1, 2, 3`; nearest CFD node selected | 40 distinct nodes; maximum target-to-node displacement `0.175776D` |
| Pressure-only arms | cylinder pressure values only; no velocity probes | verified from `--PressureOnly` run records |
| Sparse-probe Arm 4 | cylinder pressure plus probe `u,v` values | verified from absence of `--PressureOnly` with `--SparseData` |
| Dense Arm 5 | 5,000 randomly selected full-field `u,v,p` space-time samples | run record; this is a representational ceiling, not a matched optimizer ablation |

## Prior and checkpoint information boundary

- The prior consumes the 32 cylinder-pressure time series plus fixed classical
  physics and geometry. It does not fit interior CFD velocity or pressure.
- The closed-form implementation is calibrated against its own numerical
  vortex-street model at synthetic wake points; these are not CFD measurements.
- The current prior infers total drag from tap-integrated pressure drag using
  the fixed pressure fraction `0.75`. This is a prior-construction assumption,
  not an evaluation input, and must be disclosed when the prior is described.
- Trained reconstructions are evaluated from the saved checkpoint together with
  the exact inference-time wrappers recorded by that arm's `run_record.json`.
- Excluded Arms 2, 3, 14, and 16 do not enter fresh results tables.

## Training and evaluation relationship

Evaluation uses all 201 CFD snapshots and all 51,654 cropped mesh nodes. This is
a full-field reconstruction comparison, not a completely held-out test set:

- sparse arms observe the selected pressure taps, and Arm 4 also observes the
  velocity probes, across the available snapshot times;
- dense Arm 5 observes 5,000 sampled space-time points from the same CFD file;
- most evaluated interior nodes are unobserved during sparse training, but the
  evaluation interval itself is not temporally held out.

This distinction must be stated in the Methodology and Limitations sections.
